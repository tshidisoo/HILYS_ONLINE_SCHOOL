# Beginner 7: My home and my day

**Goal:** the child can name rooms and objects at home and say 3 things they do every day.
**Culture:** a home tour on camera, comparing a home abroad with a homestead (*umuzi*) in Zimbabwe.
**Flashcards:** set *Lesson 7*.

> Draft isiNdebele: check spellings before teaching.

## Review (from Lesson 6)
Play *uSija uthi…* for 3 minutes.

## New words

| isiNdebele | English |
|---|---|
| indlu | house |
| ikhaya | home |
| umuzi | homestead |
| umnyango | door |
| ifasitela | window |
| itafula | table |
| isihlalo | chair |
| umbheda | bed |

**Daily actions:** *Ngiyavuka* (I wake up), *Ngiyadla* (I eat), *Ngiyalala* (I sleep), *Ngiya esikolo* (I go to school)

## Lesson flow

1. **Greeting and review (5 min).**
2. **New words (8 min).** Use the flashcards, then play **"Touch it!"**: the child runs to touch the *itafula* or the *umnyango* and comes back to the camera.
3. **Home tour (8 min).** If the parent agrees, the child carries the tablet or laptop and shows you 3 things, naming each one. Then show 2–3 pictures of an *umuzi* in Zimbabwe and talk about what's the same and what's different.
4. **My day (4 min).** Act out *Ngiyavuka, ngiyadla, ngiya esikolo, ngiyalala* in order. Then mix them up and see if the child can put them back in order.
5. **Home task (3 min).** Stick 3 paper labels in isiNdebele on things at home (*umnyango, itafula, umbheda*).
6. **Goodbye (2 min).** *Sala kuhle!*

## Safety note
Before the home tour, check with the parent. Keep the camera in shared rooms, and skip the tour if they'd rather not.
